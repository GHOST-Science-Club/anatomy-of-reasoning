# Sentence Labeling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Label reasoning traces with resumable, concurrent runs and evaluate against human labels.

**Architecture:** A small src/labeling package with a whole-trace labeler protocol, an OpenAI-compatible implementation, a faithful splitter port, a runner, and an evaluator. A standalone converter supplies ThinkARM prefixes.

**Tech Stack:** Python 3.13, hatchling, OpenAI, PyYAML, python-dotenv, tqdm, scikit-learn, pytest.

**Spec:** docs/superpowers/specs/2026-11-04-labeling-design.md

## Global Constraints

- LABELS = Read, Analyze, Plan, Implement, Explore, Verify, Monitor, Answer.
- Preserve ThinkARM splitter behavior and prompt wording except specified fixes.
- Full prior sentence context; batch_size 20, concurrency 16, traces_in_flight 2 by default.
- At most five batch attempts; no partial trace outputs or mixed configurations.
- New labelers require one class and registry entry; runner never handles batches.
- No network in tests; do not inspect repository .env files. Mock dotenv loading in runner tests.
- Work and commit on the current branch as requested.

## Review Focus

- Torn writes must be removed before appending so resumed outputs remain parseable.
- Invalid input and duplicate ids must fail before client calls.
- Incorrect prediction counts must never silently truncate trace output.
- Missing predicted indices must exclude the affected trace from evaluation.
- Run names must stay inside runs/ and saved configuration must not contain credentials.
